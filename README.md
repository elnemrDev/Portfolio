# Freelancer Portfolio Website

A modern, professional portfolio website for a freelancer who designs websites using HTML, CSS, Python, and other technologies.

## Features
- Homepage with introduction
- Skills section
- Portfolio/projects section (2 sample projects: one static HTML/CSS, one Python-based)
- About section
- Contact form

## Getting Started
Open the `index.html` file in your browser to view the site. For the Python project demo, follow instructions in the `python_project/README.md`.

Replace sample content and images with your own for best results.
